限流被人绕过之后，攻击者把请求压在窗口边界上，同一秒内的请求量做到了阈值的两倍：窗口边界上的请求被算了两次，跨窗口查询还会漏掉一条。安全契约要求窗口区间为左开右闭，事件按时间戳进入窗口，同一时间戳的多个事件都要计入；窗口移动时过期事件必须移除，计数查询不得修改窗口内容；窗口长度使用整数毫秒，越界时间戳必须拒绝，批量查询各键独立。不变量：同一时间点重复查询结果相同，且事件按任意顺序插入后最终计数相同。

## 接口约定

窗口由查询时刻 now 和长度 window 确定，时间戳与窗口长度都使用整数毫秒。窗口可以随时间向前滑动，过期事件不应继续参与计数。

状态由事件集合构成，键之间互相隔离。加入、清理和合并操作返回可继续使用的状态，查询操作只读取状态。

主要接口如下：

- add_event 加入一条事件。
- evict 清理当前窗口之前的事件。
- count 返回当前窗口内的事件数。
- window_bounds 返回窗口的左右边界。
- merge_states 合并两个状态。
- validate_state 返回状态问题列表。
- percentile 返回窗口内事件时间戳的分位值。
- slide_batch 执行一批互相独立的窗口查询。
